# Загрузка статической версии в Tuqo

В Tuqo откройте проект «Деканат будущего» → «Загрузить деплой» → «Выбрать архив» и выберите `output/submission/tuqo-static.zip`.

В архиве уже лежит `index.html` в корне. После сборки адрес будет `https://dekanat-future.tuqo.app/`.

Эта версия специально статическая: она работает без SSR и без внешней базы, хранит демонстрационные заявки в браузере и содержит логины `alina.demo`, `maxim.demo`, `office.demo` с паролем `Student2026!`. Полный серверный вариант с D1 остаётся в основном проекте и запускается по README.
