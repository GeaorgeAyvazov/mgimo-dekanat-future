# Журнал исследования с ИИ

Дата: 6 ноября 2026 года. Это запись фактически выполненной подготовки, пригодная как основа будущего описания процесса. Здесь нет утверждения о готовом прототипе или проведённых интервью.

## Постановка задачи

Пользователь предоставил конкурсное задание и зафиксировал идею цифровизации справочного стола по примеру ВШЭ. Текущий этап прямо ограничен исследованием проблем МГИМО и полезных решений других университетов.

Ключевые сообщения пользователя, повлиявшие на работу:

- «твоя задача понять проблемы мгимо»;
- «Так же ты должен изучить лучшие тех вузы … мира и взять оттуда тоже наработки»;
- «Сейчас мы подготовку ведем полностью проект делать не правильно на данном этапе»;
- уточнение, что адаптация нужна на уровне филиала;
- требование изучать авторизованные кабинеты, потому что публичные страницы дают лишь часть картины;
- предложение войти во встроенном браузере после неудачных попыток управления Chrome.

Порядок исследования изменён после обратной связи: открытые описания использованы как вспомогательные источники, основной разбор МГИМО и ВШЭ выполнен по предоставленным сессиям.

Дополнительное уточнение пользователя: предоставлен снимок пяти услуг ВШЭ и объяснено, что онлайн-запрос доступен и для электронной, и для бумажной выдачи. Это привело к разделению способа подачи, обработки и получения в сценарии сервиса. Предположение пользователя об отсутствии такого пути в МГИМО сохранено как свидетельство и гипотеза, без объявления доказанного отсутствия услуги во всём вузе.

## Фактически использованные инструменты

| Инструмент | Для чего использован | Что им не делалось |
|---|---|---|
| Codex в настольном приложении ChatGPT | Разбор задания, постановка исследовательских вопросов, анализ наблюдений, сравнение источников и подготовка заметок | Код прототипа не создавался; модель не проводила вымышленные интервью. |
| Computer Use / Windows и `@oai/sky` | Попытки найти и прочитать открытые окна Chrome | Чтение страниц остановлено инструментом из-за неопределённого URL; авторизованные данные таким способом не получены. |
| Встроенный браузер и `cua_repl` | Обход кабинетов после входа пользователя, DOM/AX-наблюдения, снимки интерфейсов, переходы и исследование форм | Новые обращения не отправлялись, чужие данные подстановкой ID не открывались. |
| Web search / web | Поиск и чтение первичных официальных страниц вузов; документация инструмента при диагностике | Поисковая выдача не использовалась как доказательство поведения закрытого кабинета. |
| [Leanrea](https://github.com/aicodeking/leanrea), файл [SKILL.md](https://github.com/aicodeking/leanrea/blob/main/leanrea/SKILL.md) | Методика применена к копиям публичных CSS ВШЭ: выборки `rg`, DOM-классы и computed styles сопоставлены с поведением интерфейса; источники и хеши зафиксированы | Глобальная установка не выполнялась; университетские приложения и базы не декомпилировались. |
| Навык PDF | Чтение официальных инструкций о myStudies и электронных документах TUM | Отдельный итоговый PDF не создавался. |
| PowerShell, `rg`, файловые инструменты | Проверка рабочей папки и создание исследовательских Markdown-файлов | Управление Windows-приложениями через собственные скрипты не выполнялось. |
| OpenAI Docs | Проверка официальной документации при проблеме подключения Chrome | Региональная причина недоступности расширения не утверждалась без доказательств. |

Дополнительные ИИ-ассистенты или субагенты на этом этапе не запускались. Генераторы картинок, дизайн-сервисы, внешняя IDE, хостинг и сервисы разработки прототипа не использовались. Эти сведения нужно будет дополнить после следующих этапов, а не приписывать инструменты задним числом.

## Последовательность и работа с ошибками

1. Прочитано задание; разработка отложена по указанию пользователя.
2. Проверены открытые окна Chrome. Повторные попытки обычного чтения и снимка остановились одной и той же проверкой инструмента. Совет просто переключить вкладку оказался бесполезным.
3. Проведён предварительный поиск по официальным ресурсам. Его недостаточность для анализа личного кабинета признана после замечания пользователя.
4. Открыты вкладки встроенного браузера; пользователь самостоятельно вошёл в системы.
5. Изучены реальные сценарии МГИМО и ВШЭ. Отдельно проверена форма справки до доступной кнопки отправки и открыта существующая завершённая заявка. Реальные услуги для эксперимента не заказывались.
6. В ED вошли штатным переходом «Moodle» из кабинета МГИМО: авторизованный ресурс открылся через существующую сессию. Пароли не подбирались и не переносились.
7. Для «ЯУчусь» обнаружен дополнительный этап через MAX. Его прохождение не подтверждено; полноценный разбор зачётной книжки отложен.
8. Настройка виртуальной ширины 360 px не соответствовала фактическим измерениям. Успешный мобильный тест не заявлен; настройка сброшена.
9. Сопоставлены зарубежные примеры и подготовлены гипотезы, которые ещё надо проверить со студентами и сотрудниками.
10. По просьбе пользователя ВШЭ выбран основным визуальным референсом. Открыты пять форм, проверены оба формата выдачи, условное поле бумажного получения и дополнительные данные английских документов. Дополнительно разобраны готовые Transcript с файлами и русское подтверждение обучения с другим вариантом этапов. Измерены визуальные параметры, исследованы открытые CSS по методике leanrea; получен отдельный файл параметров.

## Артефакты и визуальные свидетельства

В ходе работы в чате получены снимки ленты и учебных разделов МГИМО, центра заявок, главной ВШЭ, истории заявок и состояния «ЯУчусь». Они служили материалом анализа интерфейсов.

Эти снимки содержат данные реального аккаунта и не подготовлены как публичные конкурсные иллюстрации. В папку исследования они не экспортировались. Для будущего отчёта следует делать отдельные иллюстрации с вымышленными данными или с проверенным скрытием персональной информации. Нынешние файлы не содержат персональных номеров, адресов, токенов, ссылок на подписанные вложения или реальных оценок.

Отдельно сохранён предоставленный пользователем снимок каталога пяти услуг, без данных профиля. Измеренные параметры компонентов и происхождение публичных CSS записаны в `evidence/hse-ui-reference.json`; разбор — в [05-hse-workflow-and-design.md](05-hse-workflow-and-design.md).

Точный журнал команд и ответы инструментов остаются в этом чате. Краткое изложение этапов выше не выдаётся за отдельные диалоги с другими ИИ.

## Ручные действия

Подтверждено по переписке: пользователь подобрал исходные примеры, сформулировал направление справочного стола, указал на необходимость изучения закрытых страниц и самостоятельно выполнил вход во встроенном браузере. Программирование пользователем на этом этапе не зафиксировано.
