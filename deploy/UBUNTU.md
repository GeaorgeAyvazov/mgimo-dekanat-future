# Перенос конкурсного кабинета на Ubuntu

Архив содержит готовую сборку, сервер, миграции базы данных, зафиксированные версии зависимостей и два примера конфигурации. Нужны 64-разрядная Ubuntu с glibc, Node.js 24 LTS и npm в системном PATH. Для установки зависимостей нужен доступ к реестру npm. Облачная учётная запись не требуется.

## Первый запуск

Распакуйте архив в новый каталог. От обычного пользователя внутри каталога выполните

```sh
npm ci --omit=dev
npm start
```

Локальный адрес — http://127.0.0.1:8787. Проверить с другого компьютера до подключения домена можно через SSH-туннель `ssh -L 8787:127.0.0.1:8787 user@server`. Первый запуск создаёт базу в подкаталоге data. Последующие запуски применяют только новые миграции. Перенос поставляет чистые конкурсные аккаунты.

## Постоянный запуск и HTTPS

Разместите распакованные файлы вместе с установленными зависимостями в /opt/dekanat с правами чтения для службы. Настройте DNS домена на сервер. Замените portal.example.org своим доменом в командах и в примере Caddy. Сервис принимает соединения только на loopback.

```sh
printf '%s\n' 'PUBLIC_ORIGIN=https://portal.example.org' | sudo tee /etc/dekanat.env
sudo install -m 0644 /opt/dekanat/dekanat.service /etc/systemd/system/dekanat.service
sudo systemctl daemon-reload
sudo systemctl enable --now dekanat
sudo systemctl status dekanat
```

Добавьте блок из Caddyfile.example в конфигурацию установленного Caddy. При использовании автоматического сертификата домен должен быть доступен на портах 80 и 443. Проверьте конфигурацию командой `sudo caddy validate --config /etc/caddy/Caddyfile` и примените через `sudo systemctl reload caddy`. PUBLIC_ORIGIN задаёт адрес сайта для проверки запросов и защищённой cookie. При использовании другого прокси он должен перезаписывать X-Forwarded-For.

## Обновление и резервная копия

Служба хранит сессии, заявки, выпущенные документы и вложения в /var/lib/dekanat. Перед обновлением остановите службу, сделайте закрытую резервную копию всего этого каталога и сохраните предыдущую сборку. Обновите файлы приложения, выполните npm ci в каталоге приложения и запустите службу. Для отката восстанавливают и прежнюю сборку, и соответствующую копию базы. Для переноса данных первого пробного запуска остановите оба процесса и скопируйте содержимое data в каталог данных службы с сохранением прав её пользователя. Журнал службы доступен через journalctl -u dekanat.

Публичный доступ сотрудника предназначен для конкурсного стенда с вымышленными заявками.
